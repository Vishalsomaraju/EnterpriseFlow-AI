# API Contract

## Overview
This document defines the exact API surface for the backend. All long-running operations are asynchronous (returning `202 Accepted` with a Job ID), while standard CRUD operations are synchronous.

## 1. Projects

### `GET /projects`
- **Method**: `GET`
- **Path**: `/projects`
- **Auth**: Required (Bearer Token)
- **Response**: `200 OK`
```json
[{
  "id": "uuid",
  "name": "Invoice Automation",
  "created_at": "2023-10-27T10:00:00Z"
}]
```

### `POST /projects`
- **Method**: `POST`
- **Path**: `/projects`
- **Request Body**: `{"name": "string"}`
- **Response**: `201 Created`

## 2. Documents & Extraction (Async)

### `POST /documents/:id/extract`
- **Method**: `POST`
- **Path**: `/documents/:id/extract`
- **Description**: Triggers the AI extraction pipeline.
- **Response**: `202 Accepted`
```json
{
  "jobId": "uuid",
  "status": "EXTRACTING"
}
```

### `GET /jobs/:id`
- **Method**: `GET`
- **Path**: `/jobs/:id`
- **Response**: `200 OK`
```json
{
  "status": "COMPLETED",
  "result": { "workflowId": "uuid" }
}
```
*Possible states: UPLOADED, PARSING, EXTRACTING, VALIDATING, COMPLETED, FAILED.*

## 3. Workflows

### `GET /workflows/:id/graph`
- **Method**: `GET`
- **Path**: `/workflows/:id/graph`
- **Response**: `200 OK`
```json
{
  "nodes": [...],
  "edges": [...],
  "rules": [...]
}
```

## 4. Blueprints & Implementation (Async)

### `POST /blueprints/:id/implement`
- **Method**: `POST`
- **Path**: `/blueprints/:id/implement`
- **Description**: Triggers the IBM Bob implementation pipeline.
- **Response**: `202 Accepted`
```json
{
  "buildId": "uuid",
  "status": "QUEUED"
}
```

### `GET /builds/:id/changes`
- **Method**: `GET`
- **Path**: `/builds/:id/changes`
- **Description**: Retrieves the git diff generated by Bob.
- **Response**: `200 OK`
```json
{
  "diff": "...",
  "files_changed": 3
}
```

## 5. Security & Testing

### `POST /builds/:id/test`
- **Method**: `POST`
- **Path**: `/builds/:id/test`
- **Description**: Runs tests against Bob's build. (Async)
- **Response**: `202 Accepted`

### `POST /builds/:id/security-scan`
- **Method**: `POST`
- **Path**: `/builds/:id/security-scan`
- **Description**: Runs SecurePush against the diff. (Async)
- **Response**: `202 Accepted`

## 6. Impact Analysis

### `POST /rules/:id/impact`
- **Method**: `POST`
- **Path**: `/rules/:id/impact`
- **Request Body**: `{"expression": "amount > 1000000"}`
- **Description**: Calculates the exact impact of changing a rule.
- **Response**: `200 OK`
```json
{
  "affected_files": ["src/InvoiceService.ts"],
  "affected_tests": ["tests/InvoiceApproval.test.ts"],
  "affected_nodes": ["node-uuid-123"],
  "affected_docs": ["docs/policies.md"]
}
```

## 7. Review Governance

### `POST /reviews/:id/approve`
- **Method**: `POST`
- **Path**: `/reviews/:id/approve`
- **Response**: `200 OK`

### `POST /reviews/:id/reject`
- **Method**: `POST`
- **Path**: `/reviews/:id/reject`
- **Request Body**: `{"reason": "string"}`
- **Response**: `200 OK`
